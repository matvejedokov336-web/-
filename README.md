# Snowball Fight Online

Онлайн-игра в снежки на двух игроков. Сервер Node.js + Express + Socket.IO.

## Публикация на Render
1. Создай репозиторий GitHub и загрузи в корень проекта три файла: `index.html`, `server.js`, `package.json` (README.md необязателен).
2. На Render создай **New > Web Service** и подключи этот репозиторий.
3. Укажи Build Command: `npm install`.
4. Укажи Start Command: `npm start`.
5. Выбери Free план и нажми Deploy.
6. Открой выданную ссылку `https://...onrender.com`. Оба игрока открывают её; первый создаёт комнату, второй вводит код.

Важно: выбирай Web Service, не Static Site — игре нужен сервер Socket.IO.
